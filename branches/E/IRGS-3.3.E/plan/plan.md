# IRGS — Playable Simulation with Accounts, AI Voice & Media, and a Content Store (Phase 1)

## What it is
A persistent roleplaying simulation engine where a player signs in, creates a character, and plays a campaign whose world state is durably saved, resumable, and branchable. The experience is wrapped in AI narration (text, image, and voice), voice input, and a simple store for premium content.

## Who it's for
Signed-in players exploring medieval-fantasy or historical campaigns. Later phases open creator and admin tooling; this phase proves the core engine, persistence, accounts, the AI/voice/media layer, and a working content store end to end.

## Source material & approach
The build starts from the user's existing code, layered in this order:
1. **Base — the `KingSav3ge/IRGS` repository**, delivered as a zip export uploaded into this project (the repo is private, so it is attached as a downloaded ZIP rather than cloned).
2. **Then the `IRGS Patch.zip` patch instructions**, applied on top of the repo. Codex began but did not finish implementing this patch, so finishing it is part of the work.
3. **Then the new Codex Master Instruction v1.4 doc**, the intended changes on top of the patched result — the target design.

Existing code is reused where it fits this React + FastAPI + MongoDB environment and re-implemented to the same intent where it does not. The exact state of the repo and how much of the patch Codex already applied is confirmed once the uploaded repo zip is unpacked at the start of the build.

## Core features and experience
- **Accounts**: sign in with Google (Emergent-managed) or email + password. Each player's campaigns, saves, and purchases are tied to their account.
- **Content Library**: browse campaigns and starting scenarios (seeded medieval-fantasy and historical examples); some marked premium.
- **Character Creation**: build a character with attributes, background, condition, and inventory; optionally generate or upload a portrait.
- **Story / Gameplay**: take actions that run through the engine (intent → validate → resolve → commit); world state updates, and the AI writes the player-facing narration. The engine stays the single source of truth.
- **AI layer (multi-provider text)**: narration generated by ChatGPT (OpenAI), Gemini, or Claude; provider/model selectable in the UI, default GPT-5.6 Terra.
- **Images**: AI-generated or uploaded character portraits and campaign/scenario cover art.
- **Voice out**: read narration aloud using OpenAI TTS (fast) or ElevenLabs (premium, expressive narrator/character voices), selectable.
- **Voice in**: speak an action and have it transcribed to text (OpenAI Whisper).
- **Fast text decisions (Jev)**: lightweight routing/guardrails on player text — action-intent classification and content moderation by default.
- **Save / Resume / Branching**: auto-save plus manual saves and named checkpoints; branch a new history from a checkpoint; archive and restore.
- **Chronicle**: a navigable, filterable log of committed events for the active playthrough.
- **Content store**: buy premium campaigns / content packs; purchases unlock entitlements on the account. Checkout via PayPal, Paystack, and Razorpay.

## Phase 1: what gets built now
- The authoritative simulation core (actors, locations, world clock, inventory, event pipeline) from Core 3.3 + the patch instructions, plus reliable persistence (auto-save, manual save, checkpoints, branching, archive/restore).
- Authentication: Emergent Google sign-in and email/password (JWT), with accounts owning campaigns, saves, and entitlements.
- Provider-neutral AI narration (OpenAI default GPT-5.6 Terra, Gemini, Claude) via the Emergent Universal LLM key.
- Image generation + uploads for portraits and cover art, stored in object storage (not in the database).
- Voice: OpenAI TTS and ElevenLabs for narration playback; OpenAI Whisper for spoken action input.
- Jev decisions: action-intent classification and content moderation (other Jev uses — Chronicle tagging, narration guardrail, campaign discovery tagging — deferred unless selected).
- A content store with entitlements and checkout through PayPal (USD), Paystack (NGN), and Razorpay (INR).
- Seeded medieval-fantasy and historical starting scenarios, each with a short character-creation flow.
- A clean UI across Content Library → Character Creation → Play (actions, narration text + voice, state updates) → Saves/Checkpoints → Chronicle → Store/Account.

Deferred to later phases: autonomous NPC AI decision-making, the full Campaign Workshop, the admin AI-Network management console, and advanced marketplace/account services.
