# IRGS 3.4.3 development

Historical start review now distinguishes reference eligibility, deliberate
declaration/reference use and an executable slice. New worlds receive a sourced
initial civil-day checkpoint without an invented hour or running calendar.
An explicitly selected Henry V start supports one bounded local observation;
default Henry and John retain limited modes. The App projects received context,
uses the real elapsed axis, removes courier-only prompts from Henry and preserves
explicit review, actor privacy and original-result recovery. Catalog provides
separate six-path source requirements and qualification alongside old fixtures.

All four coordinated editions are 3.4.3. Previous release remains 3.3.3; Core
compatibility remains 3.3. Main contains the current canonical installation;
superseded generated builds need not be retained. Original archive records,
dated evidence, Git history, saves and personal configuration are preserved.

The Henry observation is a bounded sourced setting with a selected simulation
rule, not general historical campaign playability. John remains held for missing
personal context. Wider freeform/combat, NPC decisions, institutional completion,
App communication controls, operator setup, live inference and full C2 remain
open. Exact source selection and new verification are recorded by the
coordinator before publication; original records retain their actual scope.
